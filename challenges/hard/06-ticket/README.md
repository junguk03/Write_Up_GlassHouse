## 설명

올해 글래스하우스 크리스마스 파티는 초대권으로 입장합니다.
신청자는 로그인하면 초대권을 받고, 운영진은 운영 사무국이 따로 발급한 초대권으로만 운영진 포털에 들어갈 수 있습니다.

운영 사무국은 초대권은 절대 위조할 수 없고, 사무국 금고에 넣어 둔 것은 운영진조차 꺼내 볼 수 없다고 자신합니다.
금고 안에 무엇이 들어 있는지 확인해 주십시오.

회원가입으로 계정을 만든 뒤 시작합니다.
