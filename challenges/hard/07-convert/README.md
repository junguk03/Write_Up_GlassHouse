# hard-07 — 확인서류 미리보기

|  |  |
|---|---|
| 난이도 | Hard |
| 분류 | Web |
| 출제 | B조 (수하, 종성) |
| 접속 | http://<출제조IP>:8011 |
| 플래그 형식 | `GlassHouse{...}` |

## 설명

위조 서류 사건 이후, 운영 사무국은 신청자가 올린 확인서류를 자동으로 다뤄
주는 도구를 새로 붙였습니다.

신청서를 내면 서류의 **미리보기**가 만들어지고, 신청서에 적은 **SNS 주소**가
제대로 열리는지도 서버가 대신 확인해 줍니다.

이 변환 도구는 운영 사무국 **내부에서만** 돌아갑니다. 바깥에서는 주소조차
닿지 않는다고 사무국은 안심하고 있습니다.

접수팀 내부에만 보관하는, 아직 공개되지 않은 자료가 하나 있다는 소문이 돕니다.

제공 계정: `applicant01 / test1234`

## 실행

```
cp .env.example .env     # 값을 모두 바꿉니다
docker compose up --build -d
```

컨테이너는 두 개입니다.

| 서비스 | 역할 | 외부 공개 |
|---|---|---|
| `web` | 원서 접수 앱 | 8011 |
| `converter` | 문서 변환 도구 | 없음 (내부 전용) |

`converter` 는 `internal` 네트워크에만 붙어 있어 바깥에서 직접 닿지 못합니다.

## 출제자 확인 사항

- `.env` 의 `FLAG_E07_CONVERT` 값이 `converter` 가 켜질 때 `/srv/flag.txt` 로 기록됩니다.
  플래그를 바꾸면 `converter` 를 다시 켜면 됩니다.
- `web` 과 `converter` 는 `uploads` 볼륨을 함께 씁니다.
