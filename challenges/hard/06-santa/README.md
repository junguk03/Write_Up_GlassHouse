## 설명

올해 글래스하우스 크리스마스 파티에서는 시크릿 산타 선물 교환을 합니다.
참가자는 위시리스트를 올리고, 운영진 엘프들이 산타를 짝지어 크리스마스 카드를 보내 줍니다.

엘프 사무실은 운영진만 들어갈 수 있고, 카드에 무엇을 적든 사무실의 비밀은 새지 않는다고 합니다.
엘프 사무실이 감춰 둔 것을 찾아 주십시오.

회원가입으로 계정을 만든 뒤 시작합니다.
