# easy-02 — 심사위원 포털

|  |  |
|---|---|
| 난이도 | Easy |
| 분류 | Web |
| 출제 | B조 (수하, 종성) |
| 접속 | http://<출제조IP>:8002 |
| 플래그 형식 | `GlassHouse{...}` |

## 설명

크리스마스 파티 초대권 신청이 시작되었습니다. 파티 운영진만 들어갈 수 있는 포털이 따로 있고,
그 안에는 신청자에게 보여서는 안 되는 내부 코드가 적혀 있다고 합니다.

평범한 신청자 계정으로 로그인한 뒤, 운영진 포털(`/admin`)에 들어가 보십시오.

회원가입으로 계정을 만든 뒤 시작합니다.
