# easy-05 — 안내 자료 보관함

|  |  |
|---|---|
| 난이도 | Easy |
| 분류 | Web |
| 출제 | B조 (수하, 종성) |
| 접속 | http://<출제조IP>:8008 |
| 플래그 형식 | `GlassHouse{...}` |

## 설명

원서 접수 시스템에 지원자용 **안내 자료 보관함**이 열렸습니다.
`/download` 로 보관함에 올라온 안내 파일을 내려받을 수 있습니다.

보관함에 공개된 안내 자료 말고, 서버가 보관함 바깥에 따로 두는 파일이 하나 있습니다.
그 파일의 내용을 찾아내십시오.

로그인 없이 접근할 수 있습니다.
