# easy-02 — 내 원서 다시 보기

|  |  |
|---|---|
| 난이도 | Easy |
| 분류 | Web |
| 출제 | A조 |
| 접속 | http://<출제조IP>:8001 |
| 플래그 형식 | `GlassHouse{...}` |

## 설명

크리스마스 파티 초대권 신청 시스템에서는 내가 낸 신청서만 다시 볼 수 있습니다.
그런데 신청 마감 직전, 정체를 알 수 없는 신청자의 신청서 한 장이 들어왔다는 소문이 돕니다.
그 신청서에 무엇이 적혀 있는지 확인해 주십시오.

회원가입으로 계정을 만든 뒤 시작합니다.
