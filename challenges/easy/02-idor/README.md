## 설명

원서 접수 시스템에서는 내가 제출한 원서만 다시 볼 수 있습니다.
그런데 접수 마감 직전, 정체를 알 수 없는 지원자의 원서 한 장이 접수되었다는 소문이 돕니다.
그 원서에 무엇이 적혀 있는지 확인해 주십시오.

제공 계정: `applicant01 / test1234`
