# easy-05 — 새 로그인 화면

|  |  |
|---|---|
| 난이도 | Easy |
| 분류 | Web |
| 출제 | B조 (수하, 종성) |
| 접속 | http://<출제조IP>:8007 |
| 플래그 형식 | `GlassHouse{...}` |

## 설명

신청 마감을 앞두고 파티 운영 사무국이 로그인 화면을 급하게 새로 만들었습니다.
이제 신청자와 운영진이 같은 화면에서 로그인합니다.

운영진 포털 첫 화면에는 명단 열람 확인 코드가 걸려 있다고 합니다.
운영진 비밀번호는 사무국 밖으로 나간 적이 한 번도 없습니다.

회원가입으로 신청자 계정을 만들 수 있습니다.
