# easy-03 — 새 로그인 화면

|  |  |
|---|---|
| 난이도 | Easy |
| 분류 | Web |
| 출제 | B조 (수하, 종성) |
| 접속 | http://<출제조IP>:8007 |
| 플래그 형식 | `GlassHouse{...}` |

## 설명

접수 마감을 앞두고 입학처가 로그인 화면을 급하게 새로 만들었습니다.
이제 지원자와 심사위원이 같은 화면에서 로그인합니다.

심사위원 포털 첫 화면에는 명단 열람 확인 코드가 걸려 있다고 합니다.
심사위원 비밀번호는 입학처 밖으로 나간 적이 한 번도 없습니다.

회원가입으로 지원자 계정을 만들 수 있습니다.
