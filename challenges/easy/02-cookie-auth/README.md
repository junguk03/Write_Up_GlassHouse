# easy-02 — 심사위원 포털

|  |  |
|---|---|
| 난이도 | Easy |
| 분류 | Web |
| 출제 | B조 (수하, 종성) |
| 접속 | http://<출제조IP>:8000 |
| 플래그 형식 | `GlassHouse{...}` |

## 설명

원서 접수 시스템이 열렸습니다. 심사위원만 들어갈 수 있는 포털이 따로 있고,
그 안에는 지원자에게 보여서는 안 되는 내부 코드가 적혀 있다고 합니다.

평범한 지원자 계정으로 로그인한 뒤, 심사위원 포털(`/admin`)에 들어가 보십시오.

제공 계정: `applicant01 / test1234`
