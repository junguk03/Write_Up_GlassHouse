## 설명

올해 추가 모집은 **1인 1원서** 원칙입니다.
원서를 낼 때마다 시스템이 이미 낸 원서가 있는지 확인하고, 있으면 접수를 거절합니다.

접수 마감일 오후, 접수 서버가 유난히 느리다는 민원이 쏟아지는 가운데
원서를 두 장 낸 지원자가 있다는 제보가 들어왔습니다.
같은 일이 정말 가능한지 직접 확인해 보십시오. 원서가 두 장 이상인 지원자에게는 확인 코드가 보입니다.

회원가입으로 계정을 만든 뒤 시작합니다.
