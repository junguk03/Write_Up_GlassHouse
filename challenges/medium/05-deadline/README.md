## 설명

올해 추가 신청은 **1인 1매** 원칙입니다.
신청서를 낼 때마다 시스템이 이미 낸 신청서가 있는지 확인하고, 있으면 신청을 거절합니다.

신청 마감일 오후, 서버가 유난히 느리다는 민원이 쏟아지는 가운데
신청서를 두 장 낸 사람이 있다는 제보가 들어왔습니다.
같은 일이 정말 가능한지 직접 확인해 보십시오. 신청서가 두 장 이상인 신청자에게는 확인 코드가 보입니다.

회원가입으로 계정을 만든 뒤 시작합니다.
