## 설명

심사 기간, 입학처에는 비밀번호를 잊었다는 문의가 끊이지 않습니다.
입학처는 아이디와 이메일만 맞으면 비밀번호를 다시 정할 수 있는 기능을 서둘러 붙였고,
지원자 계정은 사고가 나지 않도록 따로 막아 두었다고 안내했습니다.

심사위원 포털 첫 화면에는 내부 인증 코드가 걸려 있습니다.
