# medium-04 — 자기소개 미리보기

|  |  |
|---|---|
| 난이도 | Medium |
| 분류 | Web |
| 출제 | B조 (수하, 종성) |
| 접속 | http://<출제조IP>:8006 |
| 플래그 형식 | `GlassHouse{...}` |

## 설명

자기소개를 쓰다가 줄바꿈이 깨졌다는 민원이 이어지자, 입학처는 원서 작성 화면에
**미리보기** 버튼을 달았습니다. 제출하기 전에 내 자기소개가 어떻게 보일지 바로 확인할 수 있습니다.

입학처 전산 담당자는 중요한 값을 파일로 남기지 않고, 서버가 켜질 때만 건네받아 쓴다고 합니다.

회원가입으로 계정을 만든 뒤 시작합니다.
