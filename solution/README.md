# 풀이 모음

`challenges/` 와 같은 구조입니다. 문제 폴더 이름과 풀이 폴더 이름이 같습니다.

```
solution/<난이도>/<문제>/
├── solution.md     라이트업
├── exploit.py      익스플로잇 (있으면)
└── images/         캡처 (있으면)
```
